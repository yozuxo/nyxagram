> **Nyxagram is not the official Telegram app and is not affiliated with Telegram in any way. Please don't confuse the two.**

Keeps deleted messages, ghost mode, edit history, Face ID lock for chats, streaks, previous names in profiles, avatar frames, on-device translation and autocorrect.

Download [Nyxagram.ipa](https://github.com/yozuxo/nyxagram/releases/latest/download/Nyxagram.ipa) and install it with any sideloading app, for example ESign, Scarlet or Sideloadly.

### Source

`nyxa.patch` goes on top of [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS) at the commit in `UPSTREAM_COMMIT`.
